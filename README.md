# Mechanic Management System

A Python and MySQL-based Mechanic Management System developed as a Class 12 Computer Science group project.

## Features

- Customer management
- Spare parts and inventory management
- Tool management
- Repair work tracking
- Bill generation with GST calculation
- Tyre pressure checker
- Mechanic safety and maintenance manual
- Nearby spare parts shop records

## Technologies Used

- Python
- MySQL
- mysql-connector-python

## Prerequisites

- Python 3
- MySQL Server
- mysql-connector-python Python package

## How to Run

1. Install Python and MySQL Server.
2. Create a MySQL database named `mechanicdb`.
3. Create the database tables required by the application.
4. Install the required Python package:

   ```bash
   python -m pip install mysql-connector-python
   ```

5. Configure the database connection in the Python file with your own MySQL credentials.
6. Run the application:

   ```bash
   python "mechanics management.py"
   ```
